About This Project

Our Mission

The Community Emergency Information Portal was built to give residents fast, reliable access to the information they need most in an emergency — contacts, hospitals, police and fire services, first aid guidance, and safety tips — all in one simple website.

Why It Matters

In an emergency, every second counts. Searching multiple sources for a phone number or the nearest hospital can waste precious time. This portal brings that information together in one place that's easy to navigate, even under stress.

About This Build

This site was built using basic HTML and CSS as a demonstration project — no frameworks, no JavaScript libraries, just clean semantic HTML structure and a shared stylesheet across all seven pages (Home, Emergency Contacts, Hospitals, Police & Fire Service, First Aid Tips, Safety Tips, and this About page).
